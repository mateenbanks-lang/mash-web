# MASH – The AI code editor

Static single-file SPA.

## Live

Enable **GitHub Pages**: Settings → Pages → Deploy from branch `main` / root.

After Pages is on: `https://mateenbanks-lang.github.io/mash-web/`

## Local

Open `index.html` in a browser.

## Secure backend

See the `mash-secure` package for server-side auth, CSRF, AI proxy, and security controls.
